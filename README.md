## Part 1 – Imaging Technique Inspiration

### Inspiration Reference 1 – p5.js Data Structure Garden

![p5.js Garden](https://p5js.org/assets/img/tutorials/data-structure-garden/cover.png)

The p5.js “Data Structure Garden” tutorial inspired me because of its generative flower system and lifecycle animation. I want to extend this idea into a time-driven digital garden that changes through day and night cycles as well as seasonal transitions. I am particularly interested in the soft colour transitions, organic movement, and the feeling of a living environment that slowly evolves over time. This technique is beneficial for the assignment because it supports time-based interaction while also creating a poetic and immersive visual atmosphere rather than a purely functional interaction.

Reference:  
[p5.js Data Structure Garden Tutorial](https://p5js.org/tutorials/data-structure-garden/)

# Part 2 – Coding Technique Exploration

### Coding Technique – Perlin Noise + lerpColor() + Object Systems

![Generative Flowers](https://images.squarespace-cdn.com/content/v1/5c8a459650f4bb6b5efe1d98/1586038716117-2C0AYR90MY0A5Q7V9GRL/generative_flower.jpg)

I am interested in using object-oriented systems, Perlin noise, and colour interpolation techniques in p5.js to create smooth environmental transitions and organic flower movement. Perlin noise can create more natural motion compared to purely random movement, helping the flowers and particles feel alive and atmospheric. I also want to use `lerpColor()` to create gradual transitions between seasonal colour palettes and day–night lighting conditions. These coding techniques could help produce a more immersive and cinematic visual experience while supporting the assignment’s time-based mechanic requirements.
